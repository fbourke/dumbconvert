DumbConvert for Windows (beta, not signed)

1. Unzip the whole folder somewhere you keep programs, for example in Documents.
   Keep everything together: DumbConvert.exe needs the "python" and "app" folders next to it.
2. Double-click DumbConvert.exe.
3. Windows may say "Windows protected your PC": click "More info", then "Run anyway".
   It does this because the beta is not signed.

If something does not work: the app writes what went wrong to
   %APPDATA%\DumbConvert\dumbconvert.log   (paste that line into File Explorer's address bar).
Sending that file along with a bug report helps a lot.

Your scans are never changed. GPLv3, built on NegPy (https://github.com/marcinz606/NegPy).
